# 📊 Min ve Max Bulma Programı (Java)

Bu Java programı, kullanıcıdan alınan N tane sayıdan **en büyük (maksimum)** ve **en küçük (minimum)** sayıları bulur ve ekrana yazdırır.  
Program, `do-while` döngüsü kullanılarak yazılmıştır ve ilk sayıdan itibaren min ve max değerlerini günceller.

---

## 🧠 Programın Mantığı

1. Kullanıcıdan kaç sayı gireceği sorulur (`n`).  
2. İlk sayı alınır ve hem `min` hem `max` olarak başlatılır.  
3. `do-while` döngüsü ile kalan sayılar alınır ve:
   - Eğer sayı `min`’den küçükse `min` güncellenir.  
   - Eğer sayı `max`’dan büyükse `max` güncellenir.  
4. Tüm sayılar girildikten sonra **min ve max** ekrana yazdırılır.
